This file contains the best hyperparameters for the DS2DL algorithm, as 
presented in the paper for reproducibility.

n_t : # of training pixels
R_m : Mask Ratio
nk : # representative pixels in each superpixel
p : # of superpixels
l : Spatial radius R
NNs : # nearest neighbors
prctiles: percentiles
